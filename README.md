# Лапки Астаны · AstanaPets

Городской каталог кошек и собак из приютов Астаны: все животные в одном месте, понятные карточки и пожертвования напрямую на Kaspi приюта, без посредников, комиссий и регистрации.

**Сайт:** https://astanapets.vercel.app · **Демо с тестовыми питомцами:** https://lapki-demo.vercel.app

> **Статус: пилот, разработка приостановлена (ноябрь 2026).**
> Сайт работает, но проект не вышел за рамки пилота. Подробнее в разделе «Итоги пилота».

## Что умеет

- Каталог в виде рядов-каруселей с листанием стрелками и свайпом, поиск и фильтры: вид, пол, возраст, размер, стерилизация, прививки, ладит ли с детьми и животными, подходит ли для квартиры и новичка
- Карточка питомца: фото, описание, теги характера, совместимость, контакты куратора (WhatsApp, звонок)
- Сбор на конкретную цель с полосой прогресса и окном пожертвования через Kaspi
- Значок «Проверенный приют»; приют, отмеченный как непроверенный, скрывается вместе со всеми анкетами
- Ссылки на конкретного питомца, кнопка «Поделиться», FAQ
- Адаптивная вёрстка под телефон, iOS-безопасные модальные окна
- События для Яндекс.Метрики и GA4: открытие карточки, клики по контактам и Kaspi и другие

## Как устроено

```
Пост приюта → промпт-парсер (ИИ) → строка в Google Таблице (листы pets и shelters)
     → opensheet / Google gviz → React-приложение в браузере
Код: GitHub → Vercel (npm run build) → astanapets.vercel.app
```

- **Стек:** Vite, React 18, Tailwind CSS v4, lucide-react, шрифт Rubik
- **Данные:** Google Таблица вместо базы данных. Чтобы добавить питомца, достаточно добавить строку, пересобирать сайт не нужно. Фото хранятся в Cloudinary.
- **Надёжность:** если opensheet недоступен, данные берутся напрямую из Google. При сборке сохраняется снимок каталога (`scripts/snapshot-catalog.mjs`), и сайт показывает его, если таблица недоступна совсем. GitHub Actions раз в сутки запускает пересборку, чтобы снимок оставался свежим.
- **Демо-версия:** ветка `demo` с тестовыми питомцами и закрытыми контактами, её можно показывать приютам как пример.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

Подробная пошаговая инструкция для новичков, описание формата таблицы и подключения аналитики есть в [SETUP.md](SETUP.md).

## Итоги пилота

- Я написал пяти приютам Астаны. Один согласился на размещение, остальные не ответили.
- В постах приютов обычно слишком мало информации для подробной анкеты, а у крупных приютов тысячи животных и нет ресурса на описания.
- Проект волонтёрский и без дохода, поэтому поддерживать его в одиночку параллельно с учёбой оказалось нереально.

**Чему я научился:** собрал и выложил React-приложение с нуля, использовал Google Sheets как бэкенд, настроил деплой через Vercel и ежедневное обновление через GitHub Actions, автоматизировал перенос данных из постов с помощью ИИ и проверил идею на реальных организациях ещё до масштабирования.

**Если продолжать**, я бы сократил анкету до минимума (фото, кличка, вид, возраст, приют, контакт) и дал бы приютам самим дописывать детали.
