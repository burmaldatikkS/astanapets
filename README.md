# Лапки Астаны · AstanaPets

Каталог кошек и собак из приютов Астаны с прозрачными пожертвованиями.
Стек: **Vite + React + Tailwind CSS v4 + lucide-react**. Данные берутся из Google Таблицы через opensheet; если таблица недоступна, показываются тестовые данные.

```
astanapets/
├── index.html          ← заголовок страницы, иконка, место для кодов аналитики
├── package.json        ← список библиотек и команды
├── vite.config.js      ← настройки сборки (React + Tailwind)
├── public/
│   └── favicon.svg     ← иконка во вкладке браузера
└── src/
    ├── main.jsx        ← точка входа
    ├── index.css       ← подключение Tailwind
    └── App.jsx         ← весь сайт
```

## Шаг 1. Установите Node.js (один раз)

1. Откройте https://nodejs.org и скачайте версию **LTS** (20 или новее).
2. Установите, нажимая «Далее».
3. Проверьте: откройте терминал (Windows: «Командная строка» или PowerShell; macOS: «Терминал») и введите:
   ```bash
   node -v
   npm -v
   ```
   Должны появиться номера версий.

## Шаг 2. Запустите сайт у себя на компьютере

1. Распакуйте архив, например, в папку `Документы/astanapets`.
2. Откройте терминал **в этой папке**:
   - Windows: откройте папку в Проводнике, кликните в адресную строку, напишите `cmd` и нажмите Enter.
   - macOS: правый клик по папке → «Службы» → «Новый терминал по адресу папки».
3. Установите библиотеки (один раз, займёт 1–2 минуты):
   ```bash
   npm install
   ```
4. Запустите сайт:
   ```bash
   npm run dev
   ```
5. Откройте в браузере адрес, который появится в терминале (обычно http://localhost:5173).
   Правки в `src/App.jsx` сразу видны на странице. Остановить сервер: `Ctrl + C`.

6. Проверьте, что проект собирается для публикации:
   ```bash
   npm run build
   ```
   Если в конце написано `✓ built in …` — всё готово к деплою.

## Шаг 3. Залейте проект на GitHub

### Вариант А — через сайт, без команд (проще всего)

1. Зарегистрируйтесь на https://github.com.
2. Справа вверху «+» → **New repository**.
3. Название: `astanapets`. Видимость: Public или Private. Галочки README **не ставьте**. Нажмите **Create repository**.
4. На открывшейся странице нажмите ссылку **uploading an existing file**.
5. Перетащите в окно браузера **содержимое** папки проекта: `index.html`, `package.json`, `vite.config.js`, `README.md`, `.gitignore`, папки `src` и `public`.
   ⚠️ **Не загружайте** папки `node_modules` и `dist`, если они появились после шага 2.
   Файл `.gitignore` скрытый: на macOS нажмите `Cmd + Shift + .`, на Windows включите «Вид → Скрытые элементы». Если не получилось — не страшно, сайт заработает и без него.
6. Внизу нажмите **Commit changes**.

### Вариант Б — через git в терминале

Нужен установленный git (https://git-scm.com). В папке проекта:
```bash
git init
git add .
git commit -m "AstanaPets: первая версия"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/astanapets.git
git push -u origin main
```
`.gitignore` сам не пустит `node_modules` в репозиторий.

## Шаг 4. Задеплойте на Vercel

1. Откройте https://vercel.com → **Sign Up** → **Continue with GitHub**.
2. **Add New… → Project**.
3. Найдите репозиторий `astanapets` и нажмите **Import**.
   (Если его нет в списке — нажмите «Adjust GitHub App Permissions» и дайте Vercel доступ к репозиторию.)
4. Vercel сам определит **Framework Preset: Vite**. Ничего не меняйте:
   - Build Command: `npm run build`
   - Output Directory: `dist`
5. Нажмите **Deploy** и подождите ~1 минуту.
6. Готово: сайт доступен по адресу вида `https://astanapets.vercel.app`.

**Обновления публикуются сами:** каждый раз, когда вы меняете файлы на GitHub (через сайт — кнопка ✏️ у файла, или `git push`), Vercel за минуту пересобирает сайт.

## Как обновлять питомцев

Сайт читает листы `pets` и `shelters` Google Таблицы (ID таблицы — `SHEET_ID` в `src/sheetSource.js`; сначала через opensheet, при сбое — напрямую из Google, а если недоступно всё — из снимка, который сохраняется при каждой сборке). Чтобы добавить или убрать питомца, достаточно изменить таблицу — пересобирать сайт не нужно.

- Таблица должна быть открыта: «Настройки доступа» → «Все, у кого есть ссылка» → «Читатель».
- Первая строка — названия столбцов, точно как поля в `MOCK_PETS` (`id`, `name`, `species`, …).
- `species`: `dog` / `cat`; `sex`: `male` / `female`; `size`: `small` / `medium` / `large`.
- Да/нет — `TRUE` / `FALSE`. Теги в `character_tags` — через `|`.
- Чтобы скрыть пристроенного питомца, поставьте в `status` любое значение, кроме `available` (например, `adopted`).

## Подключить аналитику

1. **Яндекс.Метрика:** создайте счётчик на https://metrika.yandex.ru, вставьте его код в `index.html` внутрь `<head>`, а номер счётчика — в `YM_COUNTER_ID` в `src/App.jsx`.
2. **Google Analytics 4:** вставьте тег `gtag.js` в `<head>` файла `index.html`.

Все события (`pet_card_opened`, `reveal_contacts_clicked`, `kaspi_link_clicked` и др.) начнут уходить туда автоматически.

## Перед публичным запуском

- Замените тестовые телефоны, ссылки Kaspi и Instagram на реальные, согласованные с приютами.
- Фото в тестовых данных — с Unsplash; для реальных питомцев используйте фото от приютов.

## Если что-то не работает

| Проблема | Что сделать |
|---|---|
| `npm: command not found` | Node.js не установлен или терминал открыт до установки — переустановите и откройте терминал заново |
| Страница без стилей | Проверьте, что в `src/index.css` есть строка `@import "tailwindcss";` и выполнен `npm install` |
| Показываются тестовые питомцы вместо таблицы | Откройте консоль браузера (F12) — там будет причина; чаще всего таблица закрыта или неверно названы столбцы |
| Vercel: ошибка сборки | Откройте лог деплоя; проверьте, что на GitHub есть `package.json` и папка `src` в корне репозитория (а не внутри ещё одной папки) |
